# Logo Specifications & Guide for Grafik Tabranij (GT)

This folder contains the official logo asset for the **Grafik Tabranij (GT)** Jetton utility token on TON Blockchain.

## Current File
- **File Name:** `logo.png`
- **Resolution:** 256x256 pixels
- **Format:** PNG (with transparent/dark background)
- **Public URL (via GitHub Pages):**
  `https://galrei.github.io/grafiktabranij/logo/logo.png`

## How to Replace with Your Custom Logo:
1. Prepare your custom logo image.
2. Ensure the image is **256x256 pixels** (or 512x512 PNG) with transparent/clean background.
3. Replace `logo/logo.png` with your new file (keep the file name `logo.png`).
4. Commit and push your changes to GitHub:
   ```bash
   git add logo/logo.png
   git commit -m "Update official GT token logo"
   git push origin main
   ```
5. GitHub Pages will automatically update within 1-2 minutes.
